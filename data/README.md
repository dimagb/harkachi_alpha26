# Фоновые данные банка (A-02)
Запуск из корня: `uv run --no-project python -X utf8 data/generate_background.py`.
Проверка: `uv run --no-project --with pytest pytest -q data/`.
`background.json`: `_meta` и 40 компаний (24 ООО, 16 ИП), 60 заявок в `demo.apps`, без `demo.expected`.
Только стандартная библиотека; один `random.Random(20261023)`, фиксированная дата 2026-10-23, UTF-8/LF и стабильные ключи.
Возраст: лог-нормальное распределение с медианой около 30 месяцев, ограничение 3–120; обороты: 12 месяцев, среднее 0,3–8 млн ₽, лог-нормальное, сезонность ±15%, шум с CV 0,1–0,7.
БКИ: кредиты у 24 компаний (60%), платежи 5–35% оборота; просрочка 1–30 дней у 4, 31–90 у 2, текущая у 1.
ФНС: долг у 3 (≈8%), у 1 выше 50 000 ₽; производства у 2 (5%); банкротство у 1 и ПОД/ФТ у 1 (минимум одна при округлении редких долей).
Два стоп-ОКВЭД: 92.10 и 64.91; остальные — из INDUSTRY эталона; ИНН валидны, уникальны и не пересекаются с персонажами.
Каждое из 10 целевых состояний встречается минимум трижды; входы подбираются вызовами эталонного decide(), суммы и сроки — в PRODUCTS; загрузка в БД — задача B-10.
