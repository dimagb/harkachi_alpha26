# A-03: сквозные API-тесты
Проверяем шесть персонажей по `contracts/personas.json`, без пересчёта golden-чисел.
Сценарии: S-01…S-06, S-08, S-09, S-17, S-18 из `docs/test-scenarios.md`.
`test_harness.py` работает офлайн: схемы OpenAPI, ожидания, HTTP-ошибки и ожидание состояний.
`test_personas.py` проверяет настоящий HTTP, дозапрос, ручное решение и два пути до выдачи.
Каждый клиентский ответ карточки/списка проверяется на вложенные внутренние поля и причины.
Запуск из корня (результаты с причинами):
```powershell
uv run --no-project --python 3.12 --with pytest --with httpx --with jsonschema python -X utf8 -m pytest -q -rA tests/e2e/api
```
`E2E_BASE_URL`: по умолчанию `http://localhost:8080/api/v1`; `E2E_PASSWORD`: `demo2026`.
`E2E_TIMEOUT`: секунды на шаг конвейера, по умолчанию 60; опрос раз в секунду.
Если `/ready` не отвечает 200 за 3 секунды, весь модуль стенда получает один пропуск.
«Шаг submit: HTTP 501 NOT_IMPLEMENTED…» означает, что эндпоинт ещё не готов.
На стенде создаются новые заявки; очистку данных тесты не выполняют; M1/M2 прогоняет тимлид.
