# Скиллы для агентов Codex

Три скилла из [obra/superpowers](https://github.com/obra/superpowers) (коммит `2ce8aa1`, лицензия MIT — `LICENSE-superpowers`), без изменений: `test-driven-development`, `systematic-debugging`, `verification-before-completion`. Остальные скиллы набора не берём: они тратят лимит Plus. Вспомогательные файлы `find-polluter.sh`, `condition-based-waiting-example.ts` и тестовые сценарии не скопированы — ссылки на них в тексте можно игнорировать. Упоминания `superpowers:<имя>` означают скилл `<имя>` из этой папки.

Codex подхватывает папку `.agents/skills/` репозитория сам — и на ноутбуке, и в Codex Cloud.
