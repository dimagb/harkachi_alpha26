# Правовая база

- `research-prompts.md` — промты для Алисы AI, ChatGPT и Claude и промт сведения.
- `legal-basis.md` — сводный проверенный документ (появится после исследования). Его читает тимлид на этапах 1–3 и в ревью.
- `sources/` — исходные ответы трёх моделей.

Пока `legal-basis.md` нет, тимлид не выдумывает нормы: если правовой вопрос влияет на решение, он фиксирует его как открытый в `docs/STATE.md` и спрашивает человека.
