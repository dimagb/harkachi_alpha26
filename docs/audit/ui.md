# A-08 — автообход интерфейса на стенде

Скрипт `frontend/visual/audit.mjs` входит через форму под каждой учёткой и обходит настоящий стенд без MSW. Нажимает только то, что не меняет данные. На каждой странице собирает ошибки консоли, ответы API ≥ 400, горизонтальную прокрутку, коды и латиницу в видимом тексте, `undefined`/`NaN`/`null`/`[object Object]`, обратные кавычки, пустые заголовки и бейджи, а также нарушения `axe-core` уровня `critical`/`serious`.

## Как запустить

Из `frontend/`, стенд поднят (`docker compose up -d --build --wait`), заявки во всех состояниях созданы прогоном `tests/e2e/api/test_personas.py` и `test_objection.py`:

```powershell
npm i --no-save @axe-core/playwright
$env:VISUAL_BROWSER = "chrome"; $env:VISUAL_APP_URL = "http://localhost:8080"; node visual/audit.mjs
```

Результат пишется в `frontend/visual/out/audit/` (не коммитится): `audit.md` — сводка, `audit.json` — все страницы и находки, `*.png` — полностраничные снимки страниц с находками. Код выхода 1, если есть ошибки консоли, `pageerror`, ответы 5xx, неожиданные 4xx или сбой шага скрипта. Находки текста и `axe` в отчёт попадают, но код выхода не меняют. Ожидаемые 4xx (`EXPECTED_4XX`) и белый список латиницы (`LATIN_ALLOWED`) заданы в начале скрипта; их дополняют, а не прячут ими находки.

Необязательные переменные: `VISUAL_WORKERS` (параллельных учёток, по умолчанию 4), `VISUAL_PASSWORD` (по умолчанию `demo2026`).

## Ограничения

- Скрипт не отправляет формы и не нажимает кнопки, меняющие данные (фильтр `UNSAFE` по тексту кнопки). Поэтому не проверяются состояния после действий: ошибки после «Подписать», модальное окно перемотки времени, коды подтверждения.
- Учётки с несколькими компаниями обходятся только по компании по умолчанию. На стенде у всех учёток по одной компании.
- Ожидание загрузки: `networkidle` и исчезновение `role="status"`. Если экран показывает загрузку иначе, текст может сниматься до появления данных.
- `axe` проверяет только видимое состояние страницы, без открытых меню и модальных окон.
