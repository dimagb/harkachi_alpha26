# Демо-видео — сценарий (3–4 минуты)

Цель — то, что кейс просит показать на демонстрации: **как пользователь заполняет все поля заявки и как заявка обрабатывается системой**, и что это работающий прототип, а не картинки. Видео дополняет README, не заменяет его (организаторы: видео по желанию).

## Подготовка (до записи, ~10 мин)

1. Стенд с нуля на финальном `main`: `docker compose down -v`, затем `docker compose up -d --build --wait`. Свежая база — в очереди только фоновые заявки, номера ровные.
2. Браузер Chrome, масштаб 100 %, окно ~1440×900. Закрыть лишние вкладки, отключить уведомления Windows (Фокусировка внимания).
3. Два окна инкогнито: в одном клиент, в другом андеррайтер (входы не путаются).
4. **Заранее, до записи**, подать заявку `ooo_border` (сценарий 5 README: цель «Оборотные средства» → Экспресс-кредит, 1 000 000 ₽, 24 мес., выручка 12 000 000 ₽) — на видео не тратить время на второе заполнение формы, сразу показать банк.
5. Запись: Win+G (Xbox Game Bar) или OBS, 1080p. Голос — по желанию; если без голоса — короткие подписи при монтаже (или говорить в микрофон по тексту ниже).

## Чего не делать

- Не показывать терминал с ошибками сборки, токены, `.env`, логи.
- Не перематывать время на видео без нужды (это для жюри в README, сценарий 6).
- Не показывать фоновые учётки и внутренние коды.
- Если что-то пошло не так в кадре — переснять фрагмент, не объяснять.
