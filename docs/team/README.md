# Начни здесь — памятка участницы

Ты оператор своего агента Codex: даёшь ему задачу, подтверждаешь команды, пересылаешь вопросы. Код пишет агент, качество проверяют тесты и CI, сливает PR тимлид.

## Как взять задачу
1. Найди свою задачу в таблице `docs/TASKS.md`. Брать можно только карточки с пометкой **[готова]**.
2. Открой `docs/team/prompts/start.md` и скопируй нужный промпт: «На ноутбуке» или «В Codex Cloud». Подставь роль и ID задачи.
3. Следи за агентом раз в 30–60 минут. Как отвечать на запросы подтверждения — в конце `start.md`.
4. Агент сам пишет в Telegram «готово», «вопрос» или «блокер». Если не получилось, перешли его сообщение в группу сама.

## Правила, которые нельзя нарушать
- Агент трогает только файлы из своей карточки.
- Агент не сливает PR сам.
- Нельзя удалять или ослаблять тесты, чтобы CI стал зелёным.
- Нельзя коммитить `.env` и `.notify.env`, нельзя пересылать токены в общий чат.
- Если что-то непонятно — пиши в группу, не гадай.
