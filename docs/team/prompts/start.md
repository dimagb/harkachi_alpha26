# Стартовый промпт для любой задачи

Оператор подставляет роль и ID задачи из `docs/TASKS.md`. Ниже два варианта: для ноутбука и для облака. Копируй только текст в рамке.

## На ноутбуке (Codex CLI или приложение, в корне клона)
```
Ты — агент <РОЛЬ: backend | frontend | analytics> команды хакатона. Задача — <ID>.
1. Проверь git status (должно быть чисто, иначе остановись и скажи мне), затем выполни: git switch main && git pull --ff-only.
2. Прочитай AGENTS.md целиком и карточку <ID> в docs/TASKS.md. Больше ничего не читай, кроме файлов и разделов, названных в карточке.
3. Перескажи мне в 3–5 строках, что сделаешь, какие файлы изменишь и как проверишь приёмку. Затем сразу начинай, не жди ответа.
4. Работай строго по AGENTS.md §3: ветка, уведомление START, тесты, приёмка, PR, уведомление DONE. Вопросы и блокеры — по §4.
5. Трогай только файлы из раздела «Файлы» карточки. Не ослабляй тесты и проверки.
6. В конце напиши мне коротко по-русски: номер PR, зелёный ли CI, что осталось, есть ли вопросы к тимлиду.
```

## Исправить замечания ревью (новый или тот же чат)
```
Ты — агент <РОЛЬ>. Исправь замечания ревью в PR #<N> (задача <ID>).
Выполни: git switch <ветка PR> && git pull. Новую ветку не создавай.
Прочитай замечания: gh pr view <N> --comments. Исправь каждое, выполни приёмку карточки <ID>, запушь в ту же ветку и ответь на замечания в PR.
```

## В Codex Cloud (chatgpt.com/codex, задача с пометкой «Облако: да»)
Перед запуском проверь, что в выборе ветки стоит **main**: облако берёт код с выбранной ветки на момент старта.
```
Ты — агент <РОЛЬ> команды хакатона. Задача — <ID>. Ты работаешь в облаке: нет Docker, Postgres, gh, Telegram и доступа к GitHub — git fetch/pull/push не выполняй, ветку не создавай.
Прочитай AGENTS.md целиком и карточку <ID> в docs/TASKS.md, выполни её строго по карточке. Трогай только файлы из раздела «Файлы».
Пункты «Приёмки», которые требуют Docker или запущенного стенда, пропусти и перечисли в отчёте. Все остальные выполни и приведи их вывод.
Итоговый отчёт оформи по шаблону тела PR из AGENTS.md §6.
```
После завершения: открыть результат, нажать «Create PR», в Telegram-группу написать «<ID> готово в облаке, PR #…».

## Если агент остановился
- Ждёт подтверждения команды → прочитать её. `git`, `gh`, `uv`, `npm`, `docker`, `python` внутри проекта — подтвердить. Всё остальное — написать в группу.
- Сообщил о блокере → переслать его сообщение в группу (если бот не отправил сам).
- Кончился лимит → написать в группу «<ID>: лимит, черновой PR #…».
