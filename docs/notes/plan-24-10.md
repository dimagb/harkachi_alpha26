2. **Лана:** F-04b (слить до 12:00, остаток — в F-10) → F-05 → F-06.
3. **Катя 24.10 с 15:00:** F-08 «журнал банка и демо-управление временем» на MSW (Node, без Docker) + A-05 при наличии времени.
4. **Аня 24.10 с 15:00:** B-08 (карточка — тимлид утром, высокий режим, critic) → 25.10 B-09 → B-10a.
5. **B-10 режем:** B-10a — `GET /bank/applications`, `POST /demo/time-shift`, истечения; фоновые заявки — разовым шагом сидов в `migrate` (детерминированно, без прогона 60 заявок через worker при старте). B-10b (если останется время) — остальное.

Правило: у каждой фронтенд-задачи свои файлы, общие — только дополнение строки.
