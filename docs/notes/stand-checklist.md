# Ручная проверка на стенде — инструкция (24.10, к плану аудита §0)

Кто: человек (или любой участник) проходит руками, тимлид параллельно гоняет `test_personas` и разбирает расхождения. Время: проход 1 — ~40 мин, проход 2 — ~30 мин.
Результат записывать в `docs/audit/stand-<дата>.md`: шаг → «ок» или «расхождение: что видно / что ожидали» + скриншот. Каждое расхождение тимлид превращает в карточку отладки.

## Подготовка (холодный старт, D14)
1. Свежая папка: `git clone https://github.com/dimagb/harkachi_alpha26.git stand-check; cd stand-check` (PowerShell 5 не знает `&&`).
2. `copy .env.example .env` (Windows) — без правок.
3. Засечь время → `docker compose up -d --build` → дождаться, пока `docker compose ps` покажет все сервисы `healthy` (кроме `migrate`, он `exited 0`). Записать время.
4. Браузер (Chrome), `http://localhost:8080`. Пароль у всех учёток — `demo2026`. Каждого персонажа — в **отдельном окне инкогнито**, чтобы входы не путались.
5. Открыть DevTools (F12) → вкладка Console: на каждом экране не должно быть красных ошибок.
6. Тимлид в это время: `uv run --no-project --python 3.12 --with pytest --with httpx --with jsonschema python -X utf8 -m pytest -q tests/e2e/api/test_personas.py -rA`.

**На каждом экране смотреть:** нет кодов вида `GRADE_C`, `SF_OVERDUE`, английских слов, «undefined», «NaN»; время — московское; суммы целиком в одну строку; кнопки делают то, что написано; после действия экран обновился без перезагрузки.
