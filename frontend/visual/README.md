# Сверка F-04b с макетом

Из корня проекта запустить макеты:

```powershell
python -m http.server 8090 --bind 127.0.0.1 --directory docs/design/screens
```

В отдельном терминале, из `frontend`:

```powershell
npm ci
npx playwright install chromium
$env:VITE_USE_MSW='true'
npm run dev -- --host 127.0.0.1
```

В третьем терминале, из `frontend`:

```powershell
npm run visual
```

Скрипт входит как `ip_good` с паролем `demo2026` и открывает отдельную
MSW-фикстуру № 1042 по адресу
`/app/applications/30000000-0000-4000-8000-000000001042`.
Обычные списки заявок и персонажи не меняются. Тексты панели берутся из
`codes.md`, расчёт — из существующего MSW-калькулятора.

Результаты в игнорируемой папке `visual/out/`:

- `badge`, `nodes`, `panel`, `tile`, `detail`, `navbar` с суффиксами
  `-design.png` / `-ours.png` — пары вырезок при 1440 px;
- `computed.md` и `computed.json` — полная таблица вычисленных стилей;
- `desktop-ours.png`, `mobile-ours.png` — экраны при 1440 и 375 px;
- `nodes-mobile-design.png` — исходный мобильный вариант из `decision.html`;
- `nodes-mobile-ours.png`, `fonts.json` — мобильная лента и фактические
  шрифты текста и цифр из Chrome DevTools Protocol.

Проверяются переходы пунктов левой колонки, загрузка Onest, вертикальная
лента, скрытие указателя и отсутствие горизонтального скролла при 375 px.
Выход с кодом 1 означает ошибку проверки или необъяснённое отличие стилей.
Процент пикселей не считается; в CI `visual` не запускается.

Допустимы только два различия computed: резервные семейства после Onest
(в теме они подробнее) и полоса панели `wait.4` вместо старого `wait.6`
по новой карточке. `fonts.check = true` дополнительно подтверждается
фактическим Rendered Fonts для текста и цифр.
Содержимое истории, выручка, ставки и сроки могут отличаться от макета:
контракт и таблица решений F-04b имеют приоритет над иллюстративными данными.
CSS макета не меняется. Его Google Fonts заменяются локальными файлами
установленного `@fontsource/onest`, поэтому сверка не требует внешних шрифтов.

Адреса можно переопределить переменными `VISUAL_APP_URL`, `VISUAL_DESIGN_URL`.
Для установленного Chrome вместо Chromium: `$env:VISUAL_BROWSER='chrome'`.
